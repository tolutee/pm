# Scripts Directory

## Overview
This directory contains start and stop scripts for running the PM MVP application across different operating systems.

## Available Scripts

### Linux/Mac (`start.sh`, `stop.sh`)
- `start.sh`: Builds and runs the Docker container
- `stop.sh`: Stops and removes the running container

### Windows (`start.bat`, `stop.bat`)
- `start.bat`: Builds and runs the Docker container
- `stop.bat`: Stops and removes the running container

## Usage
Run the appropriate script for your OS to start/stop the application. The app will be available at http://localhost:8000 once started.
